# Отчет по лабораторной работе №2
## Тема: «Чтение информации из графических файлов»

---

## 1. Цель работы
Изучение структуры различных форматов растровых изображений (JPG, GIF, TIF, BMP, PNG, PCX), освоение методов извлечения метаданных и технических характеристик файлов, а также реализация высокопроизводительного инструмента для пакетной обработки графических данных.

---

## 2. Технические характеристики системы
* **Язык программирования:** C++ (стандарт C++17)
* **Фреймворк:** Qt 6.x
* **Среда разработки:** Qt Creator
* **Архитектура:** Многопоточная (основной поток UI + фоновый рабочий поток `ImageInfoReader`)
* **Компилятор:** MinGW 64-bit

---

## 3. Описание реализации

### 3.1. Архитектура приложения
Для обеспечения требования по **быстродействию** (обработка до 100 000 файлов) в приложении реализована асинхронная модель:
1.  **MainWindow:** Управляет интерфейсом, отображает таблицу `QTableWidget` и прогресс-бар.
2.  **ImageInfoReader (QThread):** Выполняет тяжелые операции чтения с диска и парсинга заголовков в отдельном потоке, чтобы интерфейс не «зависал». Связь с UI происходит через систему сигналов и слотов (`signals/slots`).

### 3.2. Алгоритмы извлечения данных
Для каждого формата используются специфические методы:

* **Размер и Глубина цвета:** Извлекаются через `QImageReader` без полной загрузки изображения в память (используется метод `readHeader`), что критически важно для производительности.
* **Разрешение (DPI):** Рассчитывается на основе физических параметров `dotsPerMeter`.
* **Сжатие:** * Для **JPEG** фиксируется наличие потерь (Lossy).
    * Для **PNG/TIFF** определяется тип фильтрации или алгоритм (LZW/Deflate).
    * Для **BMP/PCX** фиксируется отсутствие сжатия или использование RLE.



### 3.3. Извлечение матриц квантования (Extra Points)
Реализован низкоуровневый парсинг JPEG-файлов. Приложение ищет маркеры `0xFFDB` (Define Quantization Table). Найденные данные сохраняются в `QVector<QVector<int>>` и доступны для просмотра в отдельном диалоговом окне по двойному клику на ячейку таблицы.

---

## 4. Поддерживаемые форматы и их особенности

| Формат | Особенности обработки | Метод сжатия |
| :--- | :--- | :--- |
| **JPG** | Чтение маркеров APP0 (DPI) и DQT (Квантование) | Discrete Cosine Transform (DCT) |
| **PNG** | Извлечение данных из чанка `pHYs` | Deflate (без потерь) |
| **TIFF** | Обработка через теги метаданных | LZW / PackBits |
| **BMP** | Прямое чтение заголовка `BITMAPINFOHEADER` | Обычно отсутствует / RLE |
| **GIF** | Чтение глобальной таблицы цветов | LZW |
| **PCX** | Анализ заголовка (128 байт) | RLE |

## 6. Формулы и расчеты

**1. Расчет DPI (Dots Per Inch):**
Поскольку многие форматы хранят разрешение в точках на метр (DPM), используется коэффициент пересчета:
$$DPI = \text{dotsPerMeter} \times 0.0254$$

**2. Оценка коэффициента сжатия:**
Оценивается как отношение фактического размера файла к весу «сырого» несжатого массива пикселей:
$$\text{Ratio} = 100 - \left( \frac{\text{FileSize}}{\text{Width} \times \text{Height} \times \frac{\text{BitDepth}}{8}} \times 100 \right)$$
