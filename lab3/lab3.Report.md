# Лабораторная работа №3: Основы обработки цифровых изображений

**Вариант:** 6  


## 1. Цель работы
Закрепление теоретического материала и практическое освоение методов реализации алгоритмов обработки изображений: поэлементных операций, линейного контрастирования, а также глобальной и адаптивной пороговой обработки.

## 2. Задача
Разработать приложение, реализующее следующие методы согласно варианту №6:
* **Линейное контрастирование** (поэлементная операция).
* **Глобальная пороговая обработка** (2 метода: бинаризация и метод Оцу).
* **Адаптивная пороговая обработка** (алгоритм на основе локального среднего/Гаусса).

**Технологии:** Python, OpenCV, Tkinter, PIL


## 3. Описание реализованных методов

### 3.1 Линейное контрастирование
Метод используется для улучшения визуального качества малоконтрастных (блеклых) изображений. Он «растягивает» диапазон яркостей пикселей от имеющегося узкого интервала до полного диапазона $[0, 255]$.



### 3.2 Глобальная пороговая обработка
Применяется для сегментации объектов от фона, когда освещение кадра равномерно.
1.  **Binary Threshold:** Разделение по фиксированному порогу.
2.  **Метод Оцу (Otsu's Method):** Автоматический поиск порога, который минимизирует дисперсию внутри классов. Это позволяет программе самой определять оптимальный уровень черного и белого.



### 3.3 Адаптивная пороговая обработка
В отличие от глобальных методов, порог рассчитывается для каждого пикселя индивидуально на основе его окрестности. Это критически важно для изображений с градиентами освещенности или тенями.
* **Метод среднего:** Порог — среднее значение в блоке $N \times N$.
* **Метод Гаусса:** Порог — взвешенная сумма, где веса распределены по закону Гаусса.

## 5. Инструкция по использованию
1. Запустите приложение.
2. Нажмите кнопку **«Загрузить»** для выбора тестового изображения (рекомендуется использовать зашумленные или неравномерно освещенные фото).
3. Выберите нужный метод в боковой панели.
4. Настройте параметры:
    * Для адаптивного метода: **Block Size** (размер окна) и **C** (константа).
    * Для глобального метода: значение порога.
5. Нажмите **«Применить»** для отображения результата.
6. Сохраните результат через кнопку **«Сохранить»**.
