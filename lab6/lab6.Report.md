# Отчет по лабораторной работе №6
## Дисциплина: Программирование компьютерной графики (ПКГ)

**Тема:** Построение трехмерных объектов, аффинные преобразования и проекции.
**Вариант:** №6 (Буква «M»).

---

## 1. Цель работы
Изучение принципов работы с трехмерным пространством в OpenGL, реализация аффинных преобразований (перенос, поворот, масштабирование) с использованием матричного анализа и настройка нескольких областей просмотра (Viewports) для отображения ортографических проекций.

## 2. Постановка задачи
1. **Объект:** Создать каркасную 3D-модель первой буквы фамилии.
2. **Трансформации:** Реализовать управление объектом в реальном времени.
3. **Отображение матрицы:** Выводить текущую результирующую матрицу трансформаций $4 \times 4$ в отдельное графическое окно.
4. **Проекции:** Разделить экран на 4 вьюпорта: три ортографических вида (спереди, сверху, сбоку) и один перспективный/свободный вид.

## 3. Описание реализации

### 3.1. Геометрия объекта
Буква «M» представлена набором из 12 вершин, описывающих две вертикальные стойки и диагональную перемычку. Модель отрисовывается в режиме `GL_LINES`.



### 3.2. Математический аппарат
Все преобразования выполняются над однородными координатами. Для вычисления итогового положения вершин используется композиция матриц:
$$M_{total} = M_{translation} \times M_{rotation} \times M_{scale}$$

* **Матрица переноса ($T$):** позволяет перемещать объект на вектор $(dx, dy, dz)$.
* **Матрица вращения ($R$):** реализована через углы Эйлера для каждой из осей.
* **Матрица масштабирования ($S$):** изменяет размер объекта относительно локального центра.

Для вывода матрицы в Tkinter данные извлекаются напрямую из NumPy-массива, который формируется перед отрисовкой кадра.

### 3.3. Мульти-вьюпорт (Проекции)
Использование функции `glViewport(x, y, width, height)` позволяет отрисовывать сцену несколько раз в разные части окна. Для каждой проекции устанавливается своя камера через `gluLookAt`:
* **Вид OXY (Top):** Камера направлена вдоль оси Z.
* **Вид OYZ (Side):** Камера направлена вдоль оси X.
* **Вид OXZ (Front):** Камера направлена вдоль оси Y.

## 4. Управление и интерфейс

| Категория | Клавиша | Описание |
| :--- | :--- | :--- |
| **Оси (X)** | `W` / `S` | Перемещение вперед / назад |
| **Оси (Y)** | `A` / `D` | Перемещение влево / вправо |
| **Оси (Z)** | `UP` / `DOWN` | Перемещение вверх / вниз |
| **Вращение** | `1`, `2`, `3` | Выбор активной оси (X, Y или Z) |
| **Вращение** | `LEFT` / `RIGHT` | Поворот вокруг выбранной оси |
| **Масштаб** | `+` / `-` | Равномерное увеличение или уменьшение |

## 5. Программный стек
* **Python 3.10+**: Основной язык разработки.
* **PyOpenGL**: Обертка над библиотекой OpenGL для работы с графическим конвейером.
* **PyGame**: Обработка событий клавиатуры и создание окна контекста.
* **NumPy**: Математические операции с матрицами трансформации.
* **Tkinter**: Вывод данных матрицы в отдельном легковесном окне.

## 6. Результаты работы
В ходе выполнения работы была создана интерактивная среда, позволяющая:
1. Наглядно изучить влияние каждой ячейки матрицы преобразования на положение и форму объекта.
2. Понимать взаимосвязь между трехмерной сценой и её двумерными проекциями.
3. Проверить корректность применения последовательных трансформаций.
