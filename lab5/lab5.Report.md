## 1. Цель работы
Практическое освоение методов отсечения геометрических примитивов (отрезков и многоугольников) относительно заданного окна или области. Реализация классических алгоритмов Сазерленда-Коэна и Сазерленда-Ходжмена.

---

## 2. Реализованные алгоритмы

### 2.1. Алгоритм Сазерленда-Коэна (Часть 1)
Используется для отсечения отрезков прямоугольным окном.
* **Метод:** Каждой вершине отрезка присваивается 4-битный код (outcode), определяющий положение точки относительно границ окна (Верх, Низ, Право, Лево).
* **Логика:** * Если `(code1 | code2) == 0` — отрезок полностью внутри.
    * Если `(code1 & code2) != 0` — отрезок полностью снаружи.
    * В остальных случаях вычисляется точка пересечения с одной из границ окна, и отрезок укорачивается. Процесс повторяется.
* **Особенность варианта:** Пересечение вычисляется через явное уравнение прямой $y = y_1 + k(x - x_1)$.



### 2.2. Алгоритм Сазерленда-Ходжмена (Часть 2)
Используется для отсечения **выпуклого многоугольника** другим выпуклым многоугольником (или окном).
* **Метод:** Последовательное отсечение всего многоугольника каждой из бесконечных прямых, образующих границы отсекателя.
* **Процесс:** Для каждой границы создается новый список вершин. Проверяется переход каждого ребра (внутри-внутри, внутри-снаружи, снаружи-внутри, снаружи-снаружи).
* **Результат:** На выходе получается новый замкнутый многоугольник, лежащий строго внутри области отсечения.



---

## 3. Математическое описание и пример

### 3.1. Вычисление пересечений (Сазерленд-Коэн)
Для вертикальной границы окна $x = X_{edge}$ новая координата $y$ вычисляется как:
$$y = y_1 + (y_2 - y_1) \cdot \frac{X_{edge} - x_1}{x_2 - x_1}$$

Для горизонтальной границы $y = Y_{edge}$:
$$x = x_1 + (x_2 - x_1) \cdot \frac{Y_{edge} - y_1}{y_2 - y_1}$$

### 3.2. Пример работы кода (Трассировка)
Отрезок: $A(-2, 4)$, $B(8, 4)$. Окно: $[0, 0]$ до $[5, 5]$.
1.  **Код A:** `0001` (слева), **Код B:** `0010` (справа).
2.  `codeA | codeB != 0` и `codeA & codeB == 0` — требуется расчет.
3.  Осекаем по левой границе ($x=0$):
    $y = 4 + (4-4) \cdot \dots = 4$. Новая точка $A'(0, 4)$.
4.  Осекаем по правой границе ($x=5$):
    $y = 4 + (4-4) \cdot \dots = 4$. Новая точка $B'(5, 4)$.
5.  Итог: Отрезок $(0, 4) - (5, 4)$ отрисовывается как видимый.

## 4. Особенности программной реализации
* **Входные данные:** Реализовано чтение из файла `input.txt`. Программа корректно обрабатывает произвольное количество отрезков.
* **Интерфейс:** * Система координат центрирована, масштаб подбирается автоматически исходя из максимальных координат в файле.
    * **Цвета:** Окно — синее, исходные данные — серые, результат отсечения — красный/зеленый (толстая линия).
* **Динамика:** Добавлена возможность интерактивного изменения положения окна мышью (опционально) с пересчетом отсечения «на лету».

## 5. Сравнительный анализ

| Критерий | Сазерленд-Коэн | Сазерленд-Ходжмен |
| :--- | :--- | :--- |
| **Объект** | Одиночные отрезки | Целые многоугольники |
| **Сложность** | Низкая ($O(n)$) | Средняя (зависит от кол-ва вершин) |
| **Эффективность** | Лучший для простых окон | Единственный для сохранения связности фигур |

## 6. Заключение
В ходе лабораторной работы реализованы базовые алгоритмы отсечения. Алгоритм Сазерленда-Коэна показал высокую эффективность для быстрой фильтрации линий, не попадающих в поле зрения. Алгоритм Сазерленда-Ходжмена позволил корректно обрабатывать площади фигур, что критично для задач рендеринга и заливки областей.
